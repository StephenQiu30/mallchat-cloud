# P-IM-009: 安全权限 可靠性和体验增强

## 背景

当前 MallChat IM 系统已实现基础的消息发送、撤回、好友管理和群聊功能，但在安全权限方面存在以下不足：

1. **频控缺失**：消息发送等敏感操作无频率限制，可能被滥用
2. **拉黑收敛不完整**：拉黑后部分操作（如撤回）未收敛
3. **撤回权限单一**：仅发送者可撤回，群主/管理员无法管理群内消息
4. **管理员权限不足**：管理员无法移除普通成员
5. **审计事件缺失**：敏感操作无审计记录，难以追溯

## 目标

- 敏感操作有权限校验和审计记录
- 频控触发不产生违规业务事实（消息不落库）
- 补齐频控、审计和管理员错误码

## 功能需求

### FR-1: 消息发送频控

- 每用户每分钟最多发送 30 条消息
- 超频时抛出错误，消息不落库
- 使用现有 Redisson 令牌桶限流器

### FR-2: 拉黑收敛

- 被拉黑用户无法撤回对方的消息
- 现有：拉黑后无法发送私聊消息（已实现）

### FR-3: 撤回权限增强

- 群主可撤回群内任何消息
- 管理员可撤回群内普通成员的消息
- 管理员不可撤回其他管理员和群主的消息
- 撤回时间限制（2 分钟）对群主/管理员豁免

### FR-4: 管理员权限增强

- 管理员可移除普通成员
- 管理员不可移除其他管理员和群主
- 现有：仅群主可移除成员（需扩展）

### FR-5: 审计事件

- 新增 `chat_audit_event` 表
- 记录敏感操作：消息撤回、群成员变更
- 异步记录，不影响主流程性能

## 数据库变更

新增 `chat_audit_event` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 操作用户 ID |
| action | varchar(64) | 操作类型 |
| target_type | varchar(32) | 目标类型 |
| target_id | bigint | 目标 ID |
| room_id | bigint | 房间 ID（可选） |
| detail | text | 操作详情（JSON） |
| client_ip | varchar(64) | 客户端 IP |
| create_time | datetime | 创建时间 |

## 验收标准

1. 消息发送超频时返回错误，消息不落库
2. 被拉黑用户无法撤回对方消息
3. 群主/管理员可撤回群内消息（受权限规则约束）
4. 管理员可移除普通成员
5. 敏感操作在 `chat_audit_event` 表中有记录
6. 所有新测试通过
