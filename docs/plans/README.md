# Plan 文档

本目录仅保留会长期影响项目路线的计划文档。

## 适合放入

1. 产品或技术路线级计划。
2. 会跨多个版本持续生效的里程碑。
3. 需要后续团队反复引用的依赖和边界。

## 不适合放入

1. 产品需求原文。
2. 详细技术设计。
3. 验收报告或测试记录。
4. 仅服务当前执行的 todo 列表、临时进展记录或过程流水账。

## 命名建议

使用 `序号-主题-计划.md`，例如 `001-docs目录治理计划.md`。
